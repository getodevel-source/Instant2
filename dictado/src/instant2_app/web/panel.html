Servidor local administrado

El proceso de dictado administra el LLM local mientras trabaja. Si no responde y elegiste los archivos locales de runtime y modelo, los inicia y recupera automáticamente. El perfil de recursos decide cuándo duerme el modelo.

El instalador completo incluye Qwen y llama-server. En el portable o desde el código fuente, elegí archivos locales ya instalados. Los servidores remotos quedan disponibles por separado.
Se completa al instalar el paquete completo; podés elegir otro runtime.
Qwen viene incluido en la instalación completa; también admite otra ruta.
En automático se usa un dispositivo que el runtime detecte; si no inicia, se prueba CPU.
